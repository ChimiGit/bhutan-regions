## [2.0.0] - 2026-10-18

### Changed
- **BREAKING**: Updated gewog names to match official 2024-2025 administrative divisions
- Updated Chhukha dzongkhag: Changed "Metshina" to "Metakha" to match official spelling
- Updated Chhukha dzongkhag: Alphabetically reorganized gewogs for consistency
- Updated Paro dzongkhag: Changed "Doga" to "Dogar" and "Soe" to "Dopshari" to match official names
- Updated Punakha dzongkhag: Added "Barp" gewog (now has 11 gewogs instead of 10)
- Updated Trashigang dzongkhag: Changed "Kangpara" to "Kangpar" and "Uzorong" to "Udzorong", "Yangnyer" to "Yangneer" for official spelling consistency

### Updated
- Upgraded Jest from v29.7.0 to v30.5.2
- Updated all npm dependencies to latest versions
- Verified all 20 dzongkhags against official government sources
- Total gewog count: 206 (increased from 205 due to Punakha update)

### Verified
- All dzongkhag and gewog data verified against official Bhutan government websites (2024-2025)
- Dzongkha script names verified for accuracy
- All tests passing with updated data
